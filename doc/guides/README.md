# doc/guides

Guides written by whoever walked the path: a distribution, a graphics card, a language, a setup that needed a workaround. One file per subject.

A guide says what was run, on what, and what happened, so the next person can follow it exactly. Say the date and the versions; a guide that has gone stale is better replaced than quietly wrong.
