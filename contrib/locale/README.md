# contrib/locale

Translations of text Ambrose itself shows: the console, the launcher, the panel. Never the game's own text, which lives in the user's installation and is read at run time.

One file per language, named by its locale as the client spells it, such as `de` or `es`. Until the panel's own translation loader lands, these files are held here and reviewed for wording.
