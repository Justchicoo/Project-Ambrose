# contrib/proposals

A proposal is a document: what you want changed, why it helps, what it would cost, and what it depends on. The maintainer folds an accepted proposal into doc/ROADMAP.md and the phase files, which contributors never edit themselves, because a milestone in flight is being built against its own text.
