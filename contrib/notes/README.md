# contrib/notes

One file per subject, named for it. A note says what you observed, how you observed it, what you concluded, and what would show the conclusion wrong. Name your source: your own client, your own capture, your own reasoning, or a public source with its licence.

A note never carries a game file's contents. Quote a field name or a number, not a file.
